# من 10 – career-mode shorts
Code-drawn 2D episodes (canvas), rendered frame by frame to vertical MP4 (720x1280, 24 fps).
- `ep1.html` – episode 1 animation (every frame is a function of time)
- `audio_ep1.py` – synthesized soundtrack → `ep1.wav`
- `render.cjs` – `node render.cjs ep1` → `ep1.mp4` (needs Playwright + ffmpeg)
- Font: Cairo (SIL OFL, `fonts/OFL.txt`)
