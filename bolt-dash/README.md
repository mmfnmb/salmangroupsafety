# Bolt Dash

لعبة بارتي 3D بالفيزياء بتشتغل على المتصفح (موبايل وكمبيوتر). كل الأجسام في اللعبة موديلات من GitHub (Quaternius و Kenney، رخصة CC0).

## المودات
- **الشو**: 4 جولات ورا بعض (سباق ← فرق ← نجاة ← الأرض بتقع)، واللي يكسب الأخيرة ياخد التاج.
- **سباق العقبات**: أذرع بتلف، أبواب صناديق بعضها بيتكسر، نطاطات، منصات بتتحرك، سير، مناشير، فخاخ شوك، بلوكات شوك، مدافع، زنبركات، وأسهم سرعة. أسلحة: التلج + الدفع.
- **الأرض بتقع**: 4 طبقات بلاطات سداسية. أول خطوة تشرخها، والتانية توقعها، و3 ثواني واقف عليها توقعها. أسلحة: آر بي جي، قنبلة، تلج، طيران (نادر).
- **جمع النجوم** (فريقين): نجمة 1، نجمة كبيرة 3، جوهرة 5، كريستالة 10. اللي يتضرب يوقّع نص نجومه. أسلحة: الشفط + التلج.
- **كورة المضرب** (فريقين): كل لاعب بمضربه، وكل مضرب ليه قوة وسرعة ومدى وحاجة خاصة.
- **تفادي المدافع**: افضل فوق الحلبة 60 ثانية. سلاح: الطيران.
- **القمة**: اطلع على المنصات لحد التاج. سلاح: اللخبطة.
- **الحلبة**: حلبة بتصغر والكل بيضرب في الكل. أسلحة: الرشاش، الصاروخ الموجّه، القنبلة اللزقة.
- **مود البناء**: ابني ماب بـ 18 قطعة وجرّبه ضد 3 روبوتات.

## التحكم
- كمبيوتر: WASD للجري، Space نط، Shift غطس، F أو كليك للضرب، اسحب بالماوس للف الكاميرا.
- موبايل: جويستيك، وزراير نط وغطس واضرب، واسحب على الشاشة للف الكاميرا.

## التشغيل
```
cd bolt-dash
npm install
npm run build        # يطلع dist/bolt-dash.html: ملف واحد فيه كل حاجة
```
أو للتطوير: `python3 -m http.server 8000` وافتح `index.html` (بيحمّل three.js و cannon-es من jsDelivr).

## الكود
- `src/core.js`: الرسم والصوت والتخزين والموديلات والفيزياء والإفكتات.
- `src/cosmetics.js`: الألوان والإكسسوارات والمضارب وتركيبها على الشخصية.
- `src/runner.js`: الشخصية (حركة، فيزياء، تجميد، لخبطة…) ومخ الروبوتات.
- `src/level.js`: قطع الماب (أرضية، سور، أسهم سرعة، سير، زنبرك، نطاط، منشار، مدفع…).
- `src/weapons.js`: الأسلحة والصناديق والطلقات.
- `src/modes.js`: المودات.
- `src/build.js`: مود البناء.
- `src/main.js`: القائمة، البحث عن لاعبين، الشو، الكاميرا، الواجهة.

## الموديلات
- `models/*.glb`: Quaternius Ultimate Platformer Pack (CC0).
- `models/acc/*.glb`: Quaternius RPG Items / Kenney (CC0).
- `models/k/*.glb`: Kenney (platformer, prototype, weapon, blaster, minigolf, food, holiday, …) و Quaternius (CC0). الـ textures اتضمّت جوه الملفات.
