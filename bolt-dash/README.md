# Bolt Dash

لعبة سباق عقبات جماعية 3D بتشتغل على المتصفح (موبايل وكمبيوتر).

## النسخة الأولى فيها
- قائمة بداية فيها تابات: العب، ابني، الخزانة، الشوب (التلاتة الأخيرين في التحديث الجاي).
- مود **سباق العقبات**: ٨ لاعبين (إنت + ٧ روبوتات كمبيوتر)، وأول ٦ يوصلوا للعلم يتأهلوا.
- فيزياء حقيقية (cannon-es): الشخصية بتتخبط وتطير وتتقلب وتقوم تاني.
- عقبات: أذرع بتلف، نطاطات، صناديق فوق فجوة، مناشير بتتحرك، مدافع بتضرب كور، كور شوك.
- جري، نط، غطس، كاميرا من ورا تقدر تلفها، عملات، نقط حفظ، إفكتات وأصوات.

## التحكم
- كمبيوتر: WASD أو الأسهم للجري، Space للنط، Shift للغطس، واسحب بالماوس للف الكاميرا.
- موبايل: جويستيك على الشمال، وزرار النط والغطس على اليمين، واسحب على الشاشة للف الكاميرا.

## التشغيل محلياً
```
cd bolt-dash
python3 -m http.server 8000
# افتح http://localhost:8000
```
