# تخطيط الخريطة

## الفكرة
- **إسكندرية هي الخريطة الأساسية**، ومعاها **حواف مدن مصرية جنبها**.
- الحواف دي مش مدن كاملة، دي أطراف المدن اللي على حدود إسكندرية.

## إسكندرية: الأحياء ✅

| الحي | فيه إيه |
|---|---|
| 🌊 الكورنيش | الطريق الطويل على البحر، والدليفري بيعدي منه |
| 🏛️ المنشية ومحطة الرمل | وسط البلد، زحمة وأوردرات كتير |
| ⚓ بحري والأنفوشي | الصيادين والسمك، مكونات بحرية أرخص |
| 🌉 ستانلي وسيدي جابر | الكوبري والمحطة |
| 🏰 المنتزه وأبو قير | الحدايق والجمبري |
| 🏖️ العجمي | الصيف والبحر |

## الحواف: مدن جنب إسكندرية ✅

| الحافة | ناحية إيه | فيها إيه في اللعبة |
|---|---|---|
| برج العرب والعامرية | الغرب | مصانع ومخازن، مكونات بالجملة |
| كفر الدوار (البحيرة) | الجنوب الشرقي | غيطان وخضار طازة |
| رشيد (البحيرة) | الشرق | النيل بيقابل البحر، ونخل وبلح |
| الساحل / العلمين | الغرب البعيد | مصيف، وأوردرات صيفية غالية |

- الحواف ممكن تبقى أماكن تشتري منها مكونات أرخص أو أطزج، أو أماكن دليفري بعيدة بفلوس أكتر.

## لسه محتاج قرار
- كل فرقة ليها مطعم في حي مختلف، ولا كل لاعب يختار مكان مطعمه؟
