# طريقة عمل الـ100 أكلة — المكونات بترتيب دخولها في الطبخ

كل أكلة مكتوبة خطوات بالترتيب. اللاعب لازم يمشي بنفس الترتيب عشان الأكلة تطلع صح.
الحاجات اللي بين قوسين () هي العملية (تقطيع، قلي، سلق...).

---

## أكلات مصرية

1. **كشري:** عدس أسود (سلق) ← رز (طبخ مع العدس) ← مكرونة (سلق) ← حمص (سلق) ← بصل (تقطيع شرايح + قلي لحد ما يحمر) ← زيت البصل: توم + صلصة طماطم + خل (تسبيك الصلصة) ← توم + خل + مية (الدقة) ← شطة ← التركيب: رز وعدس ← مكرونة ← صلصة ← حمص ← بصل مقلي
2. **فول:** فول مدمس (تدميس على نار هادية) ← (هرس) ← زيت ← كمون ← ليمون ← طحينة ← طماطم (تقطيع مكعبات فوقه)
3. **طعمية:** فول مدشوش (نقع ليلة) ← بصل + توم + كزبرة خضرا + شبت + بقدونس (فرم مع الفول) ← (تشكيل أقراص) ← سمسم (فوق الأقراص) ← زيت (قلي غزير لحد ما تحمر)
4. **فطير مشلتت:** دقيق + ملح + مية (عجن) ← (تقطيع كور + راحة) ← سمنة + زبدة (فرد العجينة رقيقة ودهنها) ← (طي طبقات) ← (خبز في فرن عالي) ← عسل أسود (جنبه)
5. **حواوشي:** بصل + فلفل رومي (فرم) ← لحمة مفرومة + بهارات (خلط) ← عيش بلدي (فتح وحشو) ← (خبز في الفرن لحد ما يقرمش)
6. **محشي:** كوسة + باذنجان + فلفل رومي (تفريغ) ← ورق عنب (سلق خفيف) ← رز + طماطم + بقدونس + شبت (الحشوة) ← (حشو ولف) ← (رص في الحلة) ← مرقة طماطم (طبخ على نار هادية)
7. **ملوخية:** ملوخية (تخريط) ← شوربة فراخ (غلي) ← ملوخية في الشوربة ← توم + كزبرة ناشفة (تحمير في سمنة = الطشة) ← الطشة فوق الملوخية
8. **كبدة:** كبدة (تقطيع شرايح رفيعة) ← توم + كمون ← (تشويح على نار عالية) ← فلفل حار ← عيش فينو (حشو)
9. **سمك مقلي:** سمك بلطي (تنضيف + تشريح) ← ليمون + كمون (تتبيل) ← دقيق (تغطيس) ← زيت (قلي)
10. **بيض بالبسطرمة:** زبدة (تسييح في الطاسة) ← بسطرمة (تشويح) ← بيض (كسر فوقها + تسوية)
11. **كفتة:** بصل (فرم + عصر) ← بقدونس (فرم) ← لحمة مفرومة + بهارات (عجن) ← (تشكيل على أسياخ) ← فحم (شوي)
12. **فراخ مشوية:** فراخ (تشريح) ← زبادي + توم + بابريكا + ليمون (تتبيلة + راحة) ← (شوي)
13. **رز معمر:** رز (غسيل) ← لبن + زبدة (في فرن فخار) ← قشطة (فوقه) ← (طبخ في الفرن لحد ما الوش يحمر)
14. **طاجن:** بصل + توم (تشويح) ← لحمة (تحمير) ← طماطم (صلصة) ← بامية ← (في الطاجن + فرن)
15. **عيش بلدي:** خميرة + مية (تنشيط) ← دقيق + ردة (عجن) ← (تخمير) ← (تقطيع وفرد أقراص) ← (خبز في فرن عالي جدًا لحد ما ينفخ)
16. **جبنة:** جبنة بيضا + جبنة رومي + جبنة قديمة (تقطيع) ← زيت زيتون (فوقها) ← (ترص في طبق)
17. **مخلل:** خيار + جزر + لفت (تقطيع) ← ملح + خل + مية (المحلول) ← ليمون ← (تخزين في برطمان أيام)
18. **درة مشوية:** كوز درة (تقشير) ← فحم (شوي مع التقليب) ← ملح
19. **بطاطا:** بطاطا (غسيل) ← فحم أو فرن (شوي لحد ما تستوي)
20. **شوربة:** جزر (تقطيع) ← مرقة (غلي) ← لسان عصفور (يتحمر في سمنة الأول) ← (يتطبخ في المرقة)
90. **الطاسة الملكية (زعيم):** سمنة (في الطاسة) ← فول (تسخين) ← بسطرمة (تشويح) ← بيض (كسر فوق الكل) ← (تسوية في الطاسة)

## أكلات عالمية

21. **شاورما:** فراخ (تقطيع شرايح) ← تتبيلة (توم + بهارات) ← (شوي) ← عيش شامي ← توميه ← مخلل ← (لف)
22. **برجر:** لحمة (تشكيل قرص) ← (شوي) ← جبنة شيدر (فوقه وهو سخن) ← عيش برجر (تحميص) ← خس ← طماطم ← كاتشب
23. **بيتزا:** عجينة (فرد) ← صلصة طماطم ← موتزاريلا ← فلفل رومي + زيتون ← (خبز في فرن عالي)
24. **بطاطس:** بطاطس (تقشير + تقطيع أصابع) ← (غسيل + تنشيف) ← زيت (قلي) ← ملح
25. **هوت دوج:** سجق (سلق أو شوي) ← عيش هوت دوج ← مسطردة ← كاتشب
26. **مكرونة:** مكرونة (سلق) ← لحمة مفرومة (تشويح) ← صلصة بشاميل (زبدة + دقيق + لبن) ← (رص طبقات) ← (فرن)
27. **فرايد تشيكن:** فراخ (تتبيل) ← دقيق ← بيض ← بقسماط ← زيت (قلي)
28. **تاكو:** لحمة (تشويح + بهارات) ← عيش تاكو (تسخين) ← لحمة ← خس ← جبنة ← صلصة
29. **كباب:** لحمة ضاني (تقطيع مكعبات) ← بصل (تتبيل) ← (أسياخ) ← فحم (شوي)
30. **سوشي:** رز (طبخ + خل) ← ورق نوري ← رز (فرد) ← سمك سلمون + خيار + أفوكادو ← (لف) ← (تقطيع بالسكينة)
34. **بيكون:** لحم بقري مدخن (تقطيع شرايح) ← (تحمير في الطاسة لحد ما يقرمش)
35. **كاري:** فراخ (تحمير) ← كاري (تسبيك) ← كريمة ← (طبخ) ← رز (جنبه)
36. **كلوب ساندوتش:** عيش توست (تحميص) ← فراخ ← جبنة ← خس ← طماطم ← بيض ← (3 طبقات + تقطيع مثلثات)
41. **دمبلنج:** عجينة (فرد + تقطيع دواير) ← لحمة + كرنب (حشوة) ← (قفل) ← (بخار) ← صويا صوص
42. **رامن:** مرقة (غلي) ← نودلز (سلق) ← بيض (سلق + تقطيع نصين) ← بصل أخضر ← صويا صوص
43. **كورن دوج:** سجق (سيخ) ← دقيق درة (عجينة) ← (تغطيس) ← (قلي) ← كاتشب
44. **سجق:** بصل + فلفل رومي (تقطيع + تشويح) ← سجق (تقطيع + تحمير معاهم)
45. **ريش:** ريش ضاني (تتبيل) ← فحم (شوي)
48. **سندوتش طويل:** عيش فينو (فتح) ← بسطرمة ← جبنة ← خس

## مقبلات وسناكس

31. **بان كيك:** بيض + لبن (خفق) ← دقيق (خلط) ← (صب في الطاسة + تقليب) ← عسل
32. **كرواسون:** دقيق + خميرة (عجن) ← زبدة (طي جوه العجينة كذا مرة) ← (تشكيل هلال) ← (تخمير) ← (فرن)
33. **سلطة:** خس + طماطم + خيار + جزر (غسيل + تقطيع) ← زيت زيتون (تقليب)
37. **فشار:** زبدة (تسييح) ← درة فشار ← (غطا + نار لحد ما يفرقع) ← ملح
38. **فلفل حار:** فلفل حار أحمر وأخضر (غسيل + تقطيع)
39. **وافل:** بيض + لبن (خفق) ← دقيق ← (في جهاز الوافل) ← شوكولاتة سايحة
40. **جمبري:** جمبري (تقشير) ← زبدة (تسييح) ← توم ← جمبري (تشويح) ← ليمون
46. **بسكوت:** زبدة + سكر (خفق) ← فانيليا ← دقيق ← (تشكيل) ← (فرن)
47. **بلح:** بلح (غسيل + ترص في طبق)
91. **أناناس:** أناناس (تقشير + تقطيع)
92. **جوز هند:** جوز هند (كسر)
93. **عنب:** عنب (غسيل)
94. **ليمون:** ليمون (تقطيع)
95. **شطة:** فلفل حار (فرم) ← خل ← ملح (خلط)
96. **بصل:** بصل (تقشير + تقطيع)
97. **ملاحة وفلفلة:** ملح ← فلفل أسود (ملي العلب)
98. **برطمان مربى:** فراولة (تقطيع) ← سكر ← (غلي لحد ما تتقل) ← (برطمان)
99. **عسل بالطحينة:** طحينة (في طبق) ← عسل أسود (فوقها + تقليب)

## مشروبات

49. **عرقسوس:** عرقسوس (نقع في مية) ← (تصفية) ← تلج
50. **كركديه:** كركديه (نقع أو غلي) ← سكر ← (تصفية) ← تلج
51. **ليمون بالنعناع:** ليمون (عصر) ← نعناع ← سكر ← تلج (خلاط)
52. **عصير قصب:** قصب (عصر في الماكينة) ← (تصفية)
53. **شاي:** مية (غلي) ← شاي ← سكر ← نعناع
54. **قهوة:** مية ← بن + سكر + حبهان ← (تسوية على نار هادية لحد ما يطلع الوش)
55. **سحلب:** لبن (تسخين) ← سحلب (تقليب لحد ما يتقل) ← قرفة ← جوز هند + مكسرات (فوقه)
56. **كولا:** صودا ← تلج
57. **عصير مانجا:** مانجا (تقشير + تقطيع) ← سكر ← تلج (خلاط)
58. **تمر هندي:** تمر هندي (نقع) ← (تصفية) ← سكر ← تلج

## حلويات

59. **بسبوسة:** سميد + زبادي + جوز هند (خلط) ← (فرد في صينية) ← لوز (فوقها) ← (فرن) ← شربات (على البسبوسة وهي سخنة)
60. **كنافة:** عجينة كنافة (تفكيك) ← سمنة (تقليب) ← نص العجينة في الصينية ← قشطة ← باقي العجينة ← (فرن) ← شربات ← فستق
61. **أم علي:** رقاق (تكسير) ← زبيب + مكسرات + جوز هند ← لبن + سكر (تسخين + صب فوقهم) ← (فرن)
62. **رز باللبن:** رز (سلق في مية) ← لبن + سكر (طبخ) ← نشا (تتقيل) ← (يبرد) ← قرفة
63. **دونات:** دقيق + خميرة + سكر (عجن) ← (تخمير) ← (تشكيل حلقات) ← (قلي) ← شوكولاتة ← سبرينكلز
64. **آيس كريم:** لبن + كريمة + سكر + فانيليا (خلط) ← (تجميد مع التقليب) ← بسكوت كونو
65. **شوكولاتة:** كاكاو + زبدة كاكاو (تسييح) ← سكر ← (صب في قالب) ← (تبريد)
66. **كوكيز:** زبدة + سكر (خفق) ← دقيق ← شوكولاتة شيبس ← (تشكيل كور) ← (فرن)
67. **كب كيك:** بيض + سكر (خفق) ← دقيق ← (في القوالب) ← (فرن) ← كريمة شانتيه (فوقها)
68. **تورتة الفرح:** كيك (خبز + تقسيم طبقات) ← كريمة (بين الطبقات وبرة) ← فراولة ← شمع
69. **قشطوطة:** كيك (في الكاس) ← قشطة ← عسل ← فستق
70. **قشطوطة كراميل:** كيك ← قشطة ← كراميل
71. **أمبلية مانجا:** رز باللبن ← قشطة ← مانجا ← آيس كريم
72. **أمبلية بيكان:** رز باللبن ← قشطة ← بيكان ← كراميل
73. **سلانكاتي مانجا:** كنافة (تحميص) ← قشطة ← مانجا
74. **سلانكاتي فستق:** كنافة (تحميص) ← قشطة ← فستق
75. **شاورما حلوة:** كريب (تسوية) ← نوتيلا (دهن) ← موز + فراولة ← (لف + تقطيع)
76. **آيس كريم طعمية:** طعمية (قلي) ← آيس كريم (جنبها) ← شوكولاتة (فوق الكل)
77. **كشري لوتس:** رز باللبن ← مكرونة كنافة (تحميص) ← لوتس (تكسير) ← صوص كراميل
78. **نجتس آيس كريم:** آيس كريم (كور مجمدة) ← بقسماط (تغليف) ← (قلي سريع جدًا) ← صوص شوكولاتة
79. **رز بلبن بالفشار:** رز باللبن ← فشار ← كراميل
80. **بليلة:** قمح (سلق) ← لبن + سكر (تسخين) ← زبيب + جوز هند (فوقها)
81. **كريب:** بيض + لبن + دقيق (خلط) ← (صب رقيق في الطاسة) ← نوتيلا ← (طي)
82. **كيكة الهبة:** كيك (خبز) ← شوكولاتة سايحة (صب) ← آيس كريم
83. **دباديبو:** عجينة (قلي) ← قشطة (حشو) ← عسل
84. **ديباري:** كيك ← كريمة ← فواكه
85. **القنبلة:** آيس كريم (في القلب) ← شوكولاتة (غلاف) ← صوص فراولة
86. **آيس كريم بونلس:** آيس كريم (كور) ← بقسماط (تغليف) ← صوص
87. **رولات كنافة:** عجينة كنافة (فرد) ← قشطة ← (لف) ← (فرن) ← شربات
88. **مهلبية:** لبن + سكر + نشا (تقليب على النار لحد ما تتقل) ← مية ورد ← (تبريد في كاسات) ← فستق
89. **كشري مانجا:** رز باللبن ← مكرونة كنافة ← مانجا

## الزعيم الأخير

100. **ملك الأكل (زعيم):** كل المكونات — اللاعب لازم يعمل خطوة من كل قسم (نشويات ← لحوم ← خضار ← صوص ← حلو ← مشروب) بالترتيب ومن غير غلطة.
