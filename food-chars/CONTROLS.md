# تخطيط التحكم (تابلت)

## الكاميرا ✅
- **منظور الشخص التالت**: الكاميرا ورا الشخصية، زي شارع إسكندرية دلوقتي.
- تسحب بصباعين عشان تلف الكاميرا.

## الأزرار

| الحركة | إزاي |
|---|---|
| المشي | جويستيك على الشمال |
| الجري | تزق الجويستيك لآخره، أو زرار جري |
| المسك والاستعمال | زرار كبير على اليمين: تمسك مكون، تحطه، تستعمل المحطة |
| مسك الأكل الهربان | تقرب منه وتدوس المسك في الوقت الصح |
| الوصفة | زرار صغير فوق يفتح الوصفة |

## الميني جيمز (باللمس على الشاشة)

| المحطة | اللمس |
|---|---|
| التقطيع | سحب بالصباع على الأكل |
| الخلط / العجن | دواير بالصباع |
| الخلاط | دوسة مطولة |
| الطاسة / الشواية | دوسة في الوقت الصح (تشيل أو تقلب) |
| الحلة / الفرن | تسحب مؤشر النار أو الحرارة |
| الطبق | تسحب المكونات للطبق بالترتيب |
